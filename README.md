# Mounzer Alzhrawi — Services & Portfolio

A responsive portfolio for design and startup support, full-stack development and automation, IT and cloud, and IoT prototypes.

- German, English, and Arabic with right-to-left layout
- Light and dark themes with saved preference
- Filterable service examples and project details
- Animated illustrations with pause and reduced-motion support

## Hosting

This is a static website with no dependencies or build step. GitHub Pages serves `main` at the repository root.

https://elmounzer.github.io/mounzer-cloud-portfolio/

SonneGo uses a capture of the actual website. Other previews are labeled illustrations. Architecture proposals and team projects are identified in their descriptions.
